# Superstore Sales Analysis – Power BI Dashboard

## 📌 Project Overview
This project analyzes the Superstore dataset to uncover insights related to sales, profit, customer behavior, product performance, and delivery efficiency.  
The final output is an interactive Power BI dashboard designed for quick business decision-making.

---

## 🛠 Tools & Technologies
- Excel  
- Power Query  
- Power BI  
- DAX  

---

## 🎯 Key Features
- KPIs: Total Sales, Profit, Orders, Quantity, Profit Margin, Discount  
- Sales by Month & Year  
- Profit vs Sales by Category  
- Top 10 Customers by Sales  
- Top Products by Profit  
- Regional Sales Map  
- Delivery Days by Shipping Mode  

---

## 🔍 Insights
- Technology is the most profitable category, while Furniture suffers frequent losses.  
- Sales peak in Q4, especially November and December.  
- Standard Class has the slowest delivery time (~5 days).  
- A few customers contribute a large portion of total sales.
